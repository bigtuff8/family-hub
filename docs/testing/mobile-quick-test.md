# Mobile Quick Test Checklist

**Purpose:** Quick validation checklist for mobile device testing
**Time Required:** ~15 minutes

---

## Setup
- [ ] App accessible on mobile device (use local network IP or deployed URL)
- [ ] Can log in as James

---

## Contacts - Quick Checks

### View Contacts
- [ ] Contact list loads
- [ ] Cards are readable (no text overflow)
- [ ] Can scroll through list
- [ ] Tab bar (My/Family/All) works

### Create Contact
- [ ] "Add Contact" button visible
- [ ] Form opens full-screen
- [ ] Can enter text in fields
- [ ] Keyboard doesn't block fields
- [ ] Can scroll form
- [ ] Save works

### Edit Contact
- [ ] Edit button accessible
- [ ] Pre-filled data loads
- [ ] Can modify and save

### Publish to Family
- [ ] Toggle is tap-friendly
- [ ] State changes on tap
- [ ] Confirmation appears

---

## Smart Search - Quick Checks

### Search Invitees
- [ ] Search field is accessible
- [ ] Keyboard appears on tap
- [ ] Typing shows results
- [ ] Dropdown is above keyboard (or scrollable)
- [ ] Can tap to select result
- [ ] Result tags visible (may be smaller)

### Selection
- [ ] Selected items are disabled in results
- [ ] Can select multiple invitees
- [ ] Email entry works

---

## UI/UX - Quick Checks

### Navigation
- [ ] Back buttons work
- [ ] Menu/sidebar accessible
- [ ] No dead-end screens

### Touch Targets
- [ ] Buttons large enough (min 44px)
- [ ] No accidental taps
- [ ] Adequate spacing

### Visual
- [ ] No horizontal scroll
- [ ] Text is readable
- [ ] Icons are visible
- [ ] Colors have contrast
